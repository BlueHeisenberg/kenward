Why a token and not a password

There is nothing to authenticate against until you have made an account, and the first thing this wizard is going to do is ask you to make one. Until then the only secret in existence is the one this machine printed where you started it — which means reaching this page requires already being able to see that terminal.

Setup happens on 127.0.0.1. Nothing on your network can reach this page while it exists, and it stops existing the moment the account does.
